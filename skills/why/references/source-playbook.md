# Source playbooks

Use only the guidance relevant to the question. Git history is the default source; the other categories are optional leads when the available tools contain them.

- [`code-archaeology.md`](./sources/code-archaeology.md): commits, pull requests, comments, tests, and in-repo documents
- Issue trackers, design documents, and team discussions: search linked IDs, symbols, feature names, and the change window; read matching records fully
- Observability, error tracking, and analytics: use for incidents, defensive behavior, performance questions, usage, or data-backed thresholds; distinguish correlation from causation
- [`incident-postmortem.md`](./sources/incident-postmortem.md): add as a cross-cutting angle when the target looks defensive or incident-driven

When no source-specific guidance exists, use the investigator template and the available tool's own search conventions. Record unavailable sources as gaps rather than inventing results.
